## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted payload → contracts package | externally exchanged JSON for every Schema.md contract is parsed and validated here |
| persisted record → reader | a record written under one version is read by a build at a later minor; the version rule governs interpretation |
| identifier → entity | a mistyped prefixed id could silently join the wrong record in later phases |
| precision lookup → consumer | a consumer could receive a fabricated precision if the empty table returned a default |
