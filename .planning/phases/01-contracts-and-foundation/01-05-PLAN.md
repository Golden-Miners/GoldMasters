## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → repo-local vendor directory | a PostgreSQL archive is downloaded from EDB and executed on this machine |
| local user → database cluster | the cluster's authentication method determines whether any local process can read the data |
| database → network | the listen address determines whether the cluster is reachable off-host |
| workstation → stack command | one script is the developer's only documented entry point; it must not weaken the loopback rule |
