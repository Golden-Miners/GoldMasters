<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| live terminal → evidence | operator-run output is recorded as evidence, never auto-claimed; unrun stays BLOCKED never DONE |
| settings → hash → runs | the effective-config hash is the comparability anchor across runs; silent exclusion breaks it |
| SymbolResolver → broker symbols | broker symbol list is untrusted until resolved; ambiguous matches rejected, never substituted |
</threat_model>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-09 | Tampering | `services/mt5_adapter/adapter.py` precision write path | high | mitigate | Append-only enforced by frozen table + with_row as the sole path; overwrite has no code path; interval resolution tested (D-24/D-26). |
| T-02-10 | Spoofing | broker-suffix leak into `instrument_id`/strategy logic | high | mitigate | instrument_id pattern forbids suffixes (D-17); mapping table is data with one entry per canonical ID; unknown symbols → unsupported, never auto-resolved (D-49/D-53). |
| T-02-11 | Spoofing | SymbolResolver ambiguous match | medium | mitigate | Ambiguous matches (multiple broker symbols matching one canonical ID) are rejected, never silently substituted (SymbolResolver). |
</threat_model>
