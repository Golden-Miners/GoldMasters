## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| terminal → adapter | every None return and initialize False is a failure value routed to exactly one health state, never an exception leaking internals |
| adapter → API | only sanitized C-09 errors cross; retryability is code-determined, never caller-supplied |
| MT5 terminal process → TerminalManager | TerminalManager owns IPC lifecycle; starts terminal from GOLDMASTERS_MT5_TERMINAL_PATH, never terminates user-owned terminals |
