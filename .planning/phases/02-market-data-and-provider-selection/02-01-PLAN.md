<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| terminal → adapter | MT5 IPC payloads (rates arrays, ticks, symbol_info) are untrusted external input until normalized and contract-validated |
| environment → process | D-59 threshold keys and the required server timezone arrive as GOLDMASTERS_-prefixed variables |
| adapter → contracts | only Pydantic-constructed MarketBar/MarketQuote cross into API responses; raw MT5 shapes never do |
| scan → build | the reworked boundary scan is the gate that keeps the adapter read-only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege | `services/mt5_adapter/terminal.py` bare initialize | high | mitigate | Bare initialize() only; runtime assertion trade_allowed False rejects master-password sessions; no credential ever enters code/config/logs (D-46/D-47). |
| T-02-02 | Tampering | `services/mt5_adapter/*` terminal-state mutation | high | mitigate | symbol_select forbidden by name in the adapter tree via the reworked scan; operator enables Market Watch by hand (D-49). |
| T-02-03 | Spoofing / Tampering | `services/mt5_adapter/normalize.py` server-tz conversion | high | mitigate | IANA setting required fail-closed; offset sanity check reports misconfiguration rather than stamping wrong times (research §1). |
| T-02-04 | Information Disclosure | `last_error()` capture + health surface | medium | mitigate | last_error sanitized into logs only, never API details verbatim (C-09); provider object exposes no logins/server names/paths (research §5). |
| T-02-SC | Tampering | `uv` installs (`MetaTrader5` wheel) | high | mitigate | Wheel is Windows-only MetaQuotes build; pin exact version in lockfile; adapter runs only on the MT5 host; CI never requires the package (lazy gateway). |
</threat_model>
