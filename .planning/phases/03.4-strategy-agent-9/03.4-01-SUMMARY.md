## Decisions Made

- Pre-sweep window is `bars[:-3]` by definition (sweep/displacement/confirm reserve the last three); pool swings and the structure anchor both read it, so indexes align with the full bar list and the expiry anchor is the latest cluster swing.
- Displacement baseline ATR uses every true range in the pre-displacement window (period = length − 1); flat/empty baselines yield `unknown`, never a default.
- FVG wins over OB when both exist (the gap is the fresher imbalance); the zone returns concrete (low, high) bounds the retest rule taps.
- Expiry measures pool age in bars from the latest cluster swing to the confirmation bar; an unset expiry is `unknown`, an aged pool is `fail`.
